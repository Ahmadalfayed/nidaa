# نِداء (Nidaa)

لاسلكي ومحادثة ومجموعات مشفّرة واستغاثة بين الجوالات **بدون إنترنت** — Wi-Fi Direct + Bluetooth + Hotspot، بدون خدمات Google.

Offline walkie-talkie, mesh chat, encrypted groups and SOS between nearby Android phones — no internet, no Google Play services.
